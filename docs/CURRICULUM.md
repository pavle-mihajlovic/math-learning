# Curriculum

Each unit is generated by **one chat** (task `K-<id>`) and splits into 4–8 two-minute chunks.
Default order: **A → C1 → C2 → C3**, with **P** starting after A and **L** after C1, so the daily queue mixes **two tracks** at a time.

Free reference texts for sourcing problems and solutions: OpenStax *Calculus* Vol 1–3 (calculus), Hefferon *Linear Algebra* with its answer manual (linear algebra), Hammack *Book of Proof* (proofs), Axler *LADR* 4e (L-B).
