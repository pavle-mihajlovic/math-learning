# math-learning

A phone-first practice system for relearning calculus and linear algebra, on the way to Rudin's *Principles of Mathematical Analysis* and *Real and Complex Analysis*.

Planning stage. Nothing is built yet.

- [docs/ROADMAP.md](docs/ROADMAP.md): math route and build milestones
- [docs/SPEC.md](docs/SPEC.md): product spec, architecture, data model, ingestion pipeline
- [docs/CURRICULUM.md](docs/CURRICULUM.md): every unit; all 110 OpenStax Calculus sections, then LA, proofs, Spivak, Abbott, Rudin
- [docs/QUESTIONS.md](docs/QUESTIONS.md): open decisions

To work on the project, open a Claude Code session on this repo and say: *"Do task B01 from docs/ROADMAP.md."*
